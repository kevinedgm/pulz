# Espaciado

La unidad base aprobada es **4 px**.

| Token | Valor |
|---|---:|
| `space-0` | 0 px |
| `space-1` | 4 px |
| `space-2` | 8 px |
| `space-3` | 12 px |
| `space-4` | 16 px |
| `space-5` | 20 px |
| `space-6` | 24 px |
| `space-8` | 32 px |
| `space-10` | 40 px |
| `space-12` | 48 px |
| `space-16` | 64 px |
| `space-20` | 80 px |
| `space-24` | 96 px |

Todo valor salvo `0` es múltiplo de la base aprobada. La escala expresa relaciones; no obliga a rellenar espacio disponible.
