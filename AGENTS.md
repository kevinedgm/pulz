## 🍓 Fruti Squad (kiwi → lima → coco → mora)

Este proyecto incluye el Fruti Squad en `./.codex/skills`. Cada carpeta tiene su `SKILL.md`/`AGENT.md`; léelos cuando la tarea lo pida:

- **kiwi** — estructura: brief, user flow y wireframes F0–F2 adaptativos con traspaso a lima → `./.codex/skills/kiwi/`
- **lima** — gobierna: clasifica, reutiliza, registra y decide el estado de cada pieza → `./.codex/skills/lima/`
- **coco** — construye: alta fidelidad con el sistema real, implementación y auditoría → `./.codex/skills/coco/`
- **mora-docs** — documenta lo implementado y sincroniza el Design Hub (último paso del flujo) → `./.codex/skills/mora-docs/`

Flujo: **kiwi estructura → lima gobierna → coco construye → mora documenta.** Cada uno se dedica a una actividad y todos usan el perfil de proyecto de lima (`./.codex/skills/lima/profiles/<proyecto>.md`).
